# tapprot

Tap identifiers and prot tokens for idempotent workflows.

**Site:** https://theworker02.github.io/tapprot/

## Install / run

```bash
git clone https://github.com/theworker02/tapprot.git
cd tapprot
node src/cli.js
node --test
```
